Cross-domain risk chains

Internet-facing firewall rule (FW-003) combined with an unguarded owner-level service account (IAM-007) in prod-app-tier-1. A compromised workload reachable on port 8080 could exfiltrate all project resources without triggering PAM justification alerts.

GKE workload identity binding (GKE-002) grants a pod direct access to a Cloud SQL instance with public IP enabled (SQL-001). Any compromised pod in the cluster can reach the customer-records-db directly from the internet path.

A publicly readable storage bucket (GCS-002) combined with a stale service account key (IAM-003) that still holds write access to the same bucket increases the risk of build artifact tampering.
